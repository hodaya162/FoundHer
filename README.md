# FoundHer

FoundHer is a mobile-first discovery platform for modest fashion. It helps users discover products, brands, looks, and rental businesses, then redirects them to the original provider to complete a purchase or booking.

## Technology

- Next.js App Router
- TypeScript
- Tailwind CSS
- shadcn/ui
- Supabase (planned; not connected yet)
- Vercel

## Local development

Requirements:

- Node.js 22.13 or newer
- npm

Install dependencies and start the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

## Validation

```bash
npm run lint
npm run typecheck
npm run build
```

## Current scope

The repository currently contains the FoundHer visual prototype and standard Next.js infrastructure. Supabase, authentication, data fetching, and business logic are intentionally deferred to later tasks.
